# 东方Project线下活动维基

整理东方 Project 线下活动信息的社区维基。

**站点：<https://thonly.cc>**

## 组织下的仓库

| 仓库 | 说明 |
| --- | --- |
| [WikiKernel](https://github.com/THOnlyWiki/WikiKernel) | 主程序 —— Java 实现的 MediaWiki 兼容维基引擎 |
| [thonly-wiki-extensions](https://github.com/THOnlyWiki/thonly-wiki-extensions) | 官方扩展 —— 线下活动速查表 / 活动日历 / 活动分布地图 |
| [kawaii-timeless](https://github.com/THOnlyWiki/kawaii-timeless) | 站点皮肤 —— Kawaii-Timeless（Timeless 的魔改移植） |
